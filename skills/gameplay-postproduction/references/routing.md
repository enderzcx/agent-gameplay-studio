# 路由：谁做什么

> **关于本表里的工具名（公开包必读）**
>
> `editor`、`watch`、`gemini-companion`、`mimo-video` 都是作者本机的**可选外部适配器**，
> 不在本仓库内，**安装本仓库不会带来它们，也不附带任何模型、订阅、代理或登录态**。
> 本表记录的是"这类工作该由哪一类角色承担"，不是"你必须装这四个东西"。
> 换成你自己的剪辑器、你自己的视频理解通道即可；本 skill 的规范、模板与检查器不依赖它们，
> `check_postproduction.py` 只用 ffprobe/ffmpeg（可选）且完全不调用模型。
> 唯一的硬边界与工具无关：**模型给出的候选时间不能直接当剪点，必须回源核验**。

## 本 skill（`gameplay-postproduction`）

产出**规范与中间产物**：素材登记、事件/解说准备、统一时间线、审片问题单、局部修复规范。
它**不剪片、不合成、不导出、不调用视频模型**。

## 与其他 skill 的边界

| 需求 | 用 | 说明 |
|---|---|---|
| 整理录屏后期流程、写解说准备、建时间线、写审片单 | **本 skill** | 规范 + 模板 + 检查器 |
| **实际剪辑 / 合成 / 导出** | `editor` | 本 skill 只给 `edit_plan` 与时间线，不动手剪 |
| 逐帧定位、"第几秒"、`MM:SS`、逐字稿 | `watch` | 模型给的候选时间**不能**直接当剪点 |
| **视频理解调用本身**（本地文件原生读取、provenance） | `gemini-companion` | 默认 `gemini-3.8-flash-medium`；Pro 为显式第二意见；MiMo 为可用性故障后备 |
| MiMo 视频 API 直连入口 | `mimo-video` | 显式要走 MiMo 或需要公网 URL 时；一般视频理解默认走 `gemini-companion` |
| 游戏参赛评测 / 对局决策质量 | 各赛道自己的协议 | **与后期完全隔离**；本 skill 不指定评测侧模型或工具 |

## 数据流

```
录屏 ──ffprobe──► 素材登记 ──gemini-companion──► 候选事件
                                                │
                                    回源帧核验（必备）
                                                ▼
                    解说准备(五要素/三字段分列) ──► 统一时间线 ──► editor 执行剪辑
                                                                      │
                                                          实际导出 MP4 ──► 审片问题单 ──► 局部修复
```

## 冲突处理

- 本 skill 的 `references/postproduction-standard.md` 是**唯一权威来源**。
- 若把本 skill 同时装到别处（例如某个宿主插件里），**不要在两处各改一份**，指明 canonical 副本即可。
