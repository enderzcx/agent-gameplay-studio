# 路由：谁做什么

> **关于本表里的工具名（公开包必读）**
>
> `editor`、`watch`、`gemini-companion`、`mimo-video` 都是作者本机的**可选外部适配器**，
> 不在本仓库内，**安装本仓库不会带来它们，也不附带任何模型、订阅、代理或登录态**。
> 本表记录的是"这类工作该由哪一类角色承担"，不是"你必须装这四个东西"。
> 换成你自己的剪辑器、你自己的视频理解通道即可；本 skill 的规范、模板与检查器不依赖它们，
> `check_postproduction.py` / `check_timeline_audit.py` 只用 ffprobe/ffmpeg 且完全不调用模型。
>
> 唯一的硬边界与工具无关：**模型给出的候选时间与读数不能直接当剪点或事实，必须回源核验**。

## 本 skill（`gameplay-postproduction`）

产出**规范、模板、中间产物与一条短合成制作链**：素材登记、事件/解说准备、统一时间线、
字幕分页与烧录、审片问题单、局部修复规范，以及"这份时间线是否自洽"的确定性审计。
它**不内置任何视频模型**，也不做长片的剪辑/调色/包装。

## 与其他能力的边界

| 需求 | 用 | 说明 |
|---|---|---|
| 整理录屏后期流程、写解说准备、建时间线、写审片单 | **本 skill** | 规范 + 模板 + 检查器 |
| 短合成链的组装/烧字幕/原声混音 | **本 skill**（`tools/voice/`） | 单源、1x、EDL 驱动；超出的形态明确失败 |
| 长片的**剪辑 / 合成 / 导出 / 包装** | 你的剪辑器（作者本机用 `editor`） | 本 skill 只给 `edit_plan` 与时间线 |
| 逐帧定位、"第几秒"、`MM:SS`、逐字稿 | 你的定位/转写通道（作者本机用 `watch`） | 候选时间**不能**直接当剪点 |
| 游戏参赛评测 / 对局决策质量 | 各赛道自己的协议 | **与后期完全隔离** |

## 多模态路线（作者本机实测通过的那条）

**角色分工比工具名重要**——换成你自己的通道，下面四条仍然成立：

| 用途 | 交给谁 | 为什么 |
|---|---|---|
| 读**整段结构**（哪几段值得讲） | 快速视频理解模型（默认通道） | 便宜、够用来圈候选区间 |
| 读**细节**（牌名/数值/意图/UI 文字） | 先切**高清短片**或抽**裁图**，再问 | 全片分辨率下模型读数**不可靠**（实测读错牌名与数值） |
| **审听**（念对没有、断句难不难受） | **独立无字幕音轨**，画面给纯色 | 带画面会把"看来的"当"听来的"（实测发生过） |
| **审片**（字幕/遮挡/节奏） | **最终实际导出的 MP4** | 审中间产物等于没审交付物 |

本机实测的通道是 `gemini-companion`（本地文件原生读取）：默认 `beefapi` 后端的
`gemini-3.8-flash`；`agy` 需用户正常登录；MiMo 是**显式**备选/第二意见（`mimo-video` 是公网 URL 直连入口）。

### 后备与拒绝，怎么说才算诚实

- **显式后备**：人指定换通道 → 可以说"这一次用 X 通道出的结果"。
- **自动后备**：只有当它**已实现并实测**（在真触发条件下跑过）才允许写"自动后备"；
  否则必须写"未验证"。历史上曾把 **auth 失败误判成 timeout** 而触发不该触发的后备 ——
  所以任何"自动降级"的声明都要附触发条件的实测证据。
- **auth / 权限 / 内容拒绝**：**不换渠道绕过、不静默关代理、不换账号**。如实报不可用与原因，问用户要不要换。
- **大文件请求被拒（例如 405）**：用**独立压缩分析副本**或有界短分段，记录**实际 hash 与时间映射**；
  **不改母带**，也不声称"小于某个固定大小就能过"。
- 模型时点越界或读数可疑 → 标"不可靠，已回源核对，结论以源帧为准"。

## 数据流

```
录屏 ──ffprobe/preflight──► 素材登记 ──视频理解通道──► 候选事件
                                                       │
                                           回源帧核验（必备，模型读数不算事实）
                                                       ▼
                        解说准备(五要素/三字段分列) ──► 统一时间线 ──► 组装/剪辑
                                                                        │
                                                   实际导出 MP4 ──► 字幕像素抽检 ──► 审听+审片 ──► 局部修复
```

## 冲突处理

- 本 skill 的 `references/postproduction-standard.md` 是**唯一权威来源**；
  `references/runbook.md` 是**默认执行顺序**（先说"怎么做"，规范说"字段与判定"）。
- 若把本 skill 同时装到别处（例如某个宿主插件里），**不要在两处各改一份**，指明 canonical 副本即可。
