用法：复制本文件到本次成片的工作目录，逐项填写。**任何一项"否"就局部修改该段，不重做整场。**
基础流程见 `references/postproduction-standard.md`；游戏特有清单见 `references/spire-checklist.md`。

## E. 解说与字幕

| # | 检查项 | 结果 | 证据 |
|---|---|---|---|
| E1 | 开场有简短自我介绍 | 是 / 否 | |
| E2 | 口播有自然停顿，非连读赶稿 | 是 / 否 | |
| E3 | 每段配音生成后测过实长再细剪 | 是 / 否 | |
| E4 | 字幕与音频逐句一致 | 是 / 否 | |
| E5 | 说完即消失，无长驻字幕 | 是 / 否 | |
| E6 | 字幕为实际口播稿，非另行扩写 | 是 / 否 | |
| E7 | 读音无错：多音字/术语/数字/英文专名已按**实际音轨**核过（不是按原稿推断） | 是 / 否 | |
| E8 | 旁白主张与画面不矛盾：旁白对**当前画面**提出的可核实事实已回源帧核对 | 是 / 否 | |
| E9 | 音轨里没有残留下不该出现的导演提示/指令性话语 | 是 / 否 | |

> E7–E9 是**听/看实际成品**才填得出的项：E7 要有音轨证据（哪个字、什么时间、读成了什么），
> E8 要有源帧/成片时间码，E9 要明确写出你实际听完整条音轨。设计层要求见 `references/voice-design.md`。
